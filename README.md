* **Опис роботи:** 
Робота з додатком починається з того, що потрібно ввести кількість кроків для розрахунку у відповідне текстове поле. Для обчислення результатів слугує кнопка «Табулювати», після натискання якої програма виводить отримані координати у вигляді зручної таблиці. Щоб побачити результат візуально, використовується кнопка «Побудувати», яка малює графік на основі проведених обчислень. Також я додала кнопку «Очистити», яка миттєво стирає введене число, результати з таблиці та сам графік, дозволяючи швидко почати новий розрахунок. Інтерфейс є максимально простим, а внизу вікна розміщено мій підпис як автора роботи.
